# /render-report

Render a structured workflow payload into the fixed investment report format.

The renderer must include:

- Executive Conclusion
- Decision Snapshot
- Company Classification
- Core Thesis
- Key Evidence
- Valuation Summary with Bear/Base/Bull range
- Key Risks
- Execution Gate Checklist
- Investor Action Framework with price zones and position-aware suggestions
- Data Provenance

Do not include internal scorecards, calculation trace, debug logs, or formula derivations unless explicitly requested.
