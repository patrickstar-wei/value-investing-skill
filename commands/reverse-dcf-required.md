# /reverse-dcf-required

Run Reverse DCF if data is available. If not available, block explicitly.

Output:

1. Data freshness check
2. Required input table
3. Market-implied enterprise value
4. Reverse DCF mode selected:
   - FCF Growth
   - Revenue-to-FCF
   - Scenario Reverse DCF
5. Implied assumptions
6. Reasonableness judgment
7. Missing/stale data blockers, if any
