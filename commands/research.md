# /research

Generate a complete value investing research report.

Input examples:

```text
/research AAPL
/research 中国平安
/research semiconductor industry
```

Workflow:

1. Identify target
2. Select data source
3. Classify business
4. Route investment style
5. Route valuation models
6. Run valuation
7. Run bull/bear/risk review
8. Generate final report
