# Token Efficient Analysis Command

Use this command when the user wants broader coverage without making the skill token-heavy.

Rules:

1. Run classification first using compact facts only.
2. Load only the selected base route and at most two overlays by default.
3. Defer optional models unless they are material to the thesis.
4. Do not output internal scorecards or valuation calculation traces.
5. Report deferred modules in one short line.

Default output:

```text
Company Type:
Selected Route:
Models Activated:
Models Deferred:
Token Mode:
Confidence:
```
