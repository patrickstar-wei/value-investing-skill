# /pyramid-summary

Generate a pyramid-principle investment summary.

Example:

```text
/pyramid-summary GOOGL
/pyramid-summary TSLA --mode compact
/pyramid-summary AAPL --mode detailed
```

Output:

- Conclusion first
- 3-5 key reasons
- Fact / interpretation / action structure
- Symbol-enhanced readability
- Investor action framework
- Data provenance note
