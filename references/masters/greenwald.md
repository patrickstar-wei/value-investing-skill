# Greenwald Lens

## Core Use

Use Greenwald to separate no-growth value, competitive advantage value, and growth value.

## Best For

- Mature stable businesses
- Moat verification
- Franchise value checks
- Situations where DCF growth assumptions may be too optimistic

## Key Questions

- What is the no-growth EPV?
- Is franchise value supported by sustainable competitive advantage?
- Can competitors reproduce the business?
- Is growth creating value or destroying value?
- Does market value exceed no-growth value for good reasons?

## Required Evidence

- Normalized EBIT / NOPAT
- Maintenance capex
- Cost of capital
- Reproduction value when relevant
- Competitive advantage evidence
- Incremental return on capital

## Valuation Preference

- EPV
- Reproduction value
- Franchise value bridge
- Owner earnings DCF as a cross-check

## Downgrade The Lens When

- The company is early-stage and no-growth value is not meaningful.
- Segment economics are too different for a single EPV.
- Accounting normalization is impossible with available data.
